# Как помочь русской Rust Book

Вопросы, issues и pull requests можно писать по-русски. Приветствуются технические исправления, редактура перевода, проверка ссылок и перенос новых изменений официальной книги.

## Где править

- `src/` — полный текст основной книги, по одному файлу на официальный исходный файл.
- `src/SUMMARY.md` — оглавление с официальным порядком глав и отдельной ссылкой на дополнение.
- `extras/bits-bytes/` — самостоятельное дополнение с собственными примерами и тестами.
- `verification/` — ожидаемые структура и код зафиксированной официальной редакции.
- `upstream.json` — версии оригинала и русской основы.
- `upstream/manifest.json`, `upstream/en/` — снимок английского текста и зависимости глав.
- `translation-state.json` — версия исходника, до которой проверена каждая глава.

Перевод должен передавать смысл текущего английского источника естественным русским языком. Сохраняй техническую терминологию последовательно. Не переводи идентификаторы, Rust-код и вывод программ.

## Проверки

```sh
python3 scripts/check_book.py
mdbook build
python3 scripts/build_ebooks.py
python3 scripts/verify_epub.py
```

Для дополнения:

```sh
cd extras/bits-bytes
python3 scripts/check.py
cargo test --workspace --all-targets --locked
python3 scripts/run_examples.py
```

В основной книге встречаются неполные, намеренно некомпилируемые и вызывающие панику примеры. Поэтому CI не заявляет, что каждый отдельный видимый листинг должен исполняться как самостоятельная программа. Вместо этого проверяется точное совпадение 958 блоков с официальным источником указанного commit. У дополнения самостоятельные программы действительно запускаются с утверждениями.

## Обновление оригинала

Используй `python3 scripts/upstream.py prepare --ref HEAD --output .updates/next`. Он подготовит отчёт и новые контрольные данные, сохранив русский текст. Проверь затронутые главы, отметь их командой `review`, затем выполни `accept`. Полный порядок — в [docs/UPDATING.md](docs/UPDATING.md), устройство проекта — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Не меняй контрольные данные только ради прохождения проверки: они должны отражать официальный оригинал. Если исправляется только перевод, содержимое кодовых блоков и порядок заголовков сохраняются.

В описании PR укажи проблему читателя, источник изменения, выполненные проверки и использование ИИ при подготовке, если оно было. Новые изменения основного перевода и корневых инструментов распространяются по MIT или Apache-2.0; дополнение сохраняет собственную MIT-лицензию.
