# Дополнение: биты, байты и двоичные данные

Практическое дополнение к основной книге: двоичная и hex-запись, маски, флаги, порядок байтов, UTF-8, двоичные парсеры и границы сообщений.

Внутри — 12 разделов, 27 исполняемых Rust-программ, упражнения с решениями и полный учебный проект Byte Note.

- [Читать дополнение на GitHub](https://github.com/Waikizashi/russian-rustbook/tree/main/extras/bits-bytes).
- [Перейти к сайту дополнения](extras/bits-bytes/index.html).

Для первых разделов достаточно глав 3, 4 и 8 Rust Book. Для проекта с парсером пригодятся обработка ошибок, заимствование и тесты.

Это самостоятельный учебный материал. Его происхождение, программа и лицензия описаны в README дополнения.
