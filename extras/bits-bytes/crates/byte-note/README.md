# Byte Note

Учебная библиотека двоичного формата из [главы 11](../../docs/11-project.md). Использует стандартную библиотеку, обходится без `unsafe` и не публикуется автоматически в crates.io.

## Быстрый запуск

Из корня репозитория:

```sh
cargo run -p byte-note --example demo
cargo test -p byte-note
```

`encode(kind, flags, sequence, payload)` возвращает `Result<Vec<u8>, Error>`. `decode(&bytes)` проверяет целое сообщение и возвращает `Message` со срезом исходной нагрузки. Исходный буфер должен жить, пока используется сообщение.

При флаге `UTF8` полезная нагрузка обязана быть корректным UTF-8. `message.text()` возвращает `Ok(Some(text))` для текста и `Ok(None)` для бинарной нагрузки. `URGENT` — только метаданные.

## Формат и ограничения

Заголовок занимает 12 байтов, CRC — 4. Нагрузка ограничена 4096 байтами. Длина записана big-endian, номер — little-endian, итоговая CRC — big-endian. Полная спецификация и известный вектор находятся в [учебном разделе](../../docs/11-project.md#project-spec).

Декодер отклоняет неизвестные версии и флаги, усечённые и слишком длинные сообщения, лишний хвост, неправильную CRC и нарушение обещанной кодировки. CRC не обеспечивает аутентификацию или шифрование.

## Тесты

Проверяются все усечения известного сообщения, каждое одиночное изменение бита, допустимые комбинации флагов, пустая и предельная нагрузка, ошибки заголовка и UTF-8 с корректной пересчитанной CRC. Тестовый CRC-вектор также независимо проверяется через Python `zlib` в корневом скрипте проверки.
