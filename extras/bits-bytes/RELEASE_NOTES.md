Практическое дополнение к Rust Book на русском языке.

Внутри: 12 разделов, 27 исполняемых примеров, упражнения с решениями, шпаргалка и полный код двоичного формата Byte Note с тестами.

- `.epub` — для офлайн-чтения с оглавлением.
- `.md` — весь текст одним файлом.
- `source.zip` — исходники текста, примеров и проверок.
- `SHA256SUMS` — контрольные суммы файлов.

Rust 2024, минимальная версия 1.85. Самостоятельный неофициальный проект; первая редакция подготовлена с помощью ChatGPT. Текст и код — MIT.
