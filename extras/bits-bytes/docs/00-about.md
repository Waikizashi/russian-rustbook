**Биты, байты и двоичные данные в Rust**  
Практическое дополнение к *The Rust Programming Language*.  
Русский язык · открытая редакция 1.0 · 10 ноября 2026 года.

Открытое практическое дополнение к Rust Book. Инициатор проекта — [Evgenii Panarin](https://github.com/Waikizashi); первая редакция подготовлена с помощью ChatGPT. Материал развивается через исправления, тесты и вклад читателей. Это самостоятельный проект, не официальный выпуск команды Rust.

<a id="why"></a>

## Зачем оно нужно

В основной книге ты знакомишься с `u8`, `String`, срезами, владением и обработкой ошибок. Здесь мы связываем эти понятия с устройством данных: почему в байте помещается 256 вариантов, как число превращается в последовательность байтов, почему буква занимает несколько байтов и как прочитать сообщение из файла или сети.

Часть тем уже встречается в Rust Book, особенно числовые типы и UTF-8. Дополнение расширяет их практическими разборами. Побитовые маски, упакованные поля, порядок байтов, переменная длина числа и проект двоичного формата собраны здесь в последовательный маршрут.

Предполагается, что ты умеешь писать функции, использовать `if` и циклы, работать с массивами и понимаешь `Option` и `Result`. Для разделов о парсере пригодятся знания заимствования и времени жизни. Если они ещё непривычны, сначала читай разборы байтов и возвращайся к коду позже.

<a id="running"></a>

## Как запускать примеры

Короткие листинги с `fn main` можно по очереди копировать в `src/main.rs` обычного проекта Cargo. Они используют стандартную библиотеку. Команды выполняются в терминале:

```sh
cargo new byte-lab --edition 2024
cd byte-lab
cargo run
```

Все самостоятельные листинги доступны в каталоге `examples`. Сквозной проект находится в `crates/byte-note`. Из корня репозитория запусти `python3 scripts/check.py`, `cargo test --workspace` и `cargo run -p byte-note --example demo`.

Материал ориентирован на стабильный Rust и редакцию Rust 2024. В коде используются давно существующие API стандартной библиотеки; новые экспериментальные методы и nightly не нужны. Команды проверки и требования к инструментам приведены в [инструкции для участников](../CONTRIBUTING.md).

`assert_eq!` означает: «проверь, что результат равен ожидаемому». Если программа завершилась без сообщения об ошибке, проверки прошли. В упражнениях сначала попробуй вычислить результат на бумаге, затем запусти код.

<a id="main-idea"></a>

## Главная мысль

Один набор битов может означать число, флаги, часть буквы или цвет. Значение появляется, когда известны **тип, формат и правила интерпретации**. Поэтому работа с двоичными данными состоит из двух частей: извлечь нужные биты и проверить, что они допустимы по правилам формата.

Читать все разделы подряд необязательно. Для первого знакомства пройди 1, 2, 4 и 6. Для практики с файлами и сетью добавь 5, 7, 9 и 11. Разделы 3 и 8 пригодятся, когда встретишь компактный двоичный формат.
