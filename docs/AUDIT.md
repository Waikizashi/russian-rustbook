## Найденные и исправленные проблемы

| Проблема | Изменение |
|---|---|
| Общий description всех глав, повтор названия на титуле | Отдельные метаданные из содержания и редакторские overrides |
| Нет canonical, Open Graph, Twitter Card, JSON-LD | Статическая генерация в HTML с абсолютным базовым URL |
| Нет sitemap | Автоматический XML из фактической сборки обеих книг |
| Технические страницы и копии титула | noindex для print/toc/404, canonical для копий титула, исключение из sitemap |
| Отсутствует site-url для Pages подкаталога | Отдельный правильный site-url для каждой книги |
| Редактирование ведёт в src/src и .book-src | Ссылки ведут на существующие src и docs; добавлена проверка |
| Невалидные ARIA у переключателя оглавления и маленькие touch targets | Настоящая кнопка с Enter/Space и увеличенные области нажатия; no-JS fallback сохранён |
| Устаревший unload-listener блокирует back/forward cache | Удалён из готового UI-скрипта с пересчётом имени; навигация назад проверяется |
| У разделов нет основного H1, панель тоже H1 | Нормализация только готового HTML с сохранением якорей |
| Проверка ссылок пропускает абсолютные пути и CSS | Проверка origin, базового пути, CSS-ресурсов и якорей |
| Поиск удаляет кириллицу | Unicode-aware индекс обеих книг и регрессии русских запросов |
| Pages не зависит от всех проверок проекта | Deployment запускается после site, book и обеих Rust-матриц |
| Неизменяемый checksum mdBook не закреплён локально | SHA-256 официального архива закреплён в установщике |
| Еженедельная проверка зависит от apt Pandoc | Закреплённый Pandoc 3.13 через общий установщик |
| README обещает отсутствующие файлы downloads | Честные ссылки на Releases/артефакты и локальную сборку |
| Новые сборочные файлы могут попасть в downloads | Шаблоны готовых EPUB/PDF/MD/ZIP добавлены в gitignore |

## Что требует владельца

Получить реальные токены Google Search Console и Bing Webmaster Tools, записать их в `config/seo.json`, опубликовать, подтвердить ресурс и отправить sitemap. Индексация и поисковые позиции не подтверждены этим аудитом. Порядок: [SEO.md](SEO.md).

About/Website/Topics редактируются через интерфейс, если подключённый API не даёт такой операции; готовые значения приведены в [DEPLOYMENT.md](DEPLOYMENT.md). Корневой robots.txt при необходимости размещается отдельно в `waikizashi.github.io`, а не в подкаталоге проекта.
